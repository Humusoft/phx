phx.BushingJoint

Bushing joint (compliant fixed joint)

Class  phx.BushingJoint  |  Superclass: phx.base.Joint

Description

phx.BushingJoint realizes the compliant counterpart of a fixed joint — an elastic bushing that holds two bodies together with per-axis linear and angular stiffness and damping across all six degrees of freedom. Where phx.FixedJoint locks the relative pose rigidly, phx.BushingJoint lets it deflect against a springy bedding.

Very stiff springs are clamped by the solver for numerical stability — the ceiling scales with the connected bodies' mass/inertia and shrinks as the time step grows, so beyond a certain stiffness the response no longer stiffens. Use more substeps (a smaller time step) for stiffer bushings, or phx.FixedJoint for a truly rigid connection.

Creation

Syntax

bushing = phx.BushingJoint(bodyA,bodyB) bushing = phx.BushingJoint(___,Name,Value)

Description

bushing = phx.BushingJoint(bodyA,bodyB) creates a compliant 6-DOF connection between two bodies at their origins. Set custom connection points with PointA and PointB.

The end-stop limits bound the relative travel on each axis. Setting lower > upper disables the stop, leaving the axis free (spring only) — this is the default; lower == upper locks the axis rigidly at that value; lower < upper limits the travel to that range while the spring acts inside it.

Reaction feedback and the MutualCollisions switch (collisions between the connected bodies, default false) are inherited from phx.base.Joint.

The sprung axes are all three axes of the joint frames, so there is no single free axis for the inherited AxisA/AxisB to describe. They are still writable and move the frame's Z axis like any other rotation helper — to orient the bushing deliberately, use EulerAnglesA or TransformA.

Examples

Compliant mount between two bodies

clf; view(3); axis equal; grid on; camlight headlight;

a = phx.Body("Type", "static", "Position", [0 0 2]);
b = phx.Body("Position", [0 0 2]);

phx.BushingJoint(a, b);

sim = phx.Simulation;
b.applyForce([0 0 -30]);
sim.step(3, 600, 5);
delete(sim);

Bushing with a hard end stop

A soft silent-block that bottoms out: the vertical (Z) travel is limited to ±5 mm while X and Y stay free (lower > upper). The body's weight would sink far past that on so soft a spring, so the end stop catches it at 5 mm.

clf; view(3); axis equal; grid on; camlight headlight;

a = phx.Body("Type", "static", "Position", [0 0 2]);
b = phx.Body("Position", [0 0 2]);

phx.BushingJoint(a, b, ...
    "LinearStiffness", [1e3 1e3 1e3], ...
    "LowerLinearLimits", [1 1 -0.005], ...   % X, Y free; Z lower stop
    "UpperLinearLimits", [-1 -1 0.005]);      % Z upper stop (+-5 mm)

sim = phx.Simulation;
b.applyForce([0 0 -30]);
sim.step(3, 600, 5);
delete(sim);
