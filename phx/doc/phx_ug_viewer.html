Interactive Viewer

A ready-made 3-D window with a sky, camera, shadows and mouse editing

Instead of bare axes you can use the enhanced viewer phx.extra.Viewer with a sky, a movable camera and the ability to edit the scene with the mouse:

phx.extra.Viewer("clear", "DefaultCameraPosition", [3 4 5]);
% then add bodies into the current axes as usual
phx.Body("Position", [0 0 2], "Shape", {"Sphere"});
phx.Body("Shape", {"Box", "Size", [3 2 1]});
ControlAction
Left mouse buttonPan the camera, or drag the selected body to move it.
Middle button (or Shift + left)Orbit the camera, or drag the selected body to rotate it.
Right buttonContext menu — snapshot, material, properties, scene load/save …
WheelZoom; with Shift, the field of view.
Double-clickSelect / deselect a body (edit mode).
F1, F2, F3, F5Help, lighting mode, view mode, free run.
Home, PgUp / PgDownRestore the default view, cycle the preset views.
Arrows / WASDPan and move the camera. Off by default — switch on with ArrowsEnable / WASDEnable.

Shadows

MATLAB axes light objects but do not cast shadows, which makes a flying body hard to place: in a perspective view there is nothing to say how high above the floor it is. phx.PlanarShadow fills that gap by projecting the geometry of the chosen bodies onto a plane:

% shadow on the ground plane, lit from above and slightly aside
phx.PlanarShadow([b1 b2], "LightDirection", [-0.4 -0.3 -1]);

The plane does not have to be fixed. With Anchor it is defined in the local frame of a body and follows it, so bodies can cast their shadow on a tilting plate, a moving platform or a wall. It is a projection rather than a rendered shadow, so bodies neither shadow each other nor block each other's shadow; see the reference page for the full list of limitations.

See also phx.extra.Viewer, phx.PlanarShadow
