phx.GenericJoint

Generic joint

Class  phx.GenericJoint  |  Superclass: phx.base.Joint

Description

phx.GenericJoint realizes a constraint with six degrees of freedom — three translations and three rotations — each of them independently free, locked or bounded by a pair of hard end stops. It is the building block the other joints are special cases of: locking all six axes gives a fixed joint, leaving one translation free a prismatic joint, leaving one rotation free a revolute joint.

The degrees of freedom are the axes of the joint frame of body A. The translation of body B along them is bounded by LowerLinearLimits and UpperLinearLimits, its rotation about them by LowerAngularLimits and UpperAngularLimits, measured in the right-handed sense. On each axis independently:

LimitsBehaviour
lower == upperThe axis is locked at that value. This is the default.
lower < upperThe motion is bounded to that range, free inside it.
lower > upperThe axis is free, the joint does not constrain it.
Note. All limits default to zero, so a joint created without them locks all six axes and behaves like a phx.FixedJoint — open only the axes that are meant to move. The limits are read when the simulation is built, so set them at construction time; assigning them later does not affect a running simulation.
Note. Rotation about the Y axis of the joint frame is limited to roughly ±90 deg by the solver and degenerates near that value. Leave the Y axis locked or narrowly bounded, and orient the joint frames so that a freely rotating axis is X or Z.

Creation

Syntax

joint = phx.GenericJoint(bodyA,bodyB) joint = phx.GenericJoint(___,Name,Value)

Description

joint = phx.GenericJoint(bodyA,bodyB) connects two bodies rigidly, with the joint frame of each of them coinciding with the local coordinate system of that body and all six degrees of freedom locked.

joint = phx.GenericJoint(___,Name,Value) sets properties using name-value arguments.

Input Arguments

ArgumentTypeDescription
bodyA, bodyBphx.Body (scalar)The two bodies connected by the joint.

Properties

Reaction feedback (ForceA, TorqueA, ForceB, TorqueB) and the MutualCollisions switch (collisions between the connected bodies, default false) are inherited from phx.base.Joint.

The degrees of freedom are all three axes of the joint frames, each with its own limits, so there is no single free axis for the inherited AxisA/AxisB to describe. They are still writable and move the frame's Z axis like any other rotation helper — to orient the frames deliberately, use EulerAnglesA or TransformA.

Examples

Slide along the local X axis between two end stops

clf; view(3); axis equal; grid on; camlight headlight;

a = phx.Body("Type", "static", "Position", [0 0 2]);
b = phx.Body("Position", [0 0 2], "LinearVelocity", [2 0 0]);

% Open translation along x to [-1, 1]; the other five axes stay locked
phx.GenericJoint(a, b, ...
    "LowerLinearLimits", [-1 0 0], "UpperLinearLimits", [1 0 0]);

sim = phx.Simulation;
sim.step(2, 400, 5);          % slides to the +1 stop and rests against it
delete(sim);

Hinge with end stops

clf; view(3); axis equal; grid on; camlight headlight;

a = phx.Body("Type", "static", "Position", [0 0 2]);
b = phx.Body("Position", [0 1 2]);

% Open rotation about x to [-0.4, 1.5] rad; the arm swings down and stops
phx.GenericJoint(a, b, "PointB", [0 -1 0], ...
    "LowerAngularLimits", [-0.4 0 0], "UpperAngularLimits", [1.5 0 0]);

sim = phx.Simulation;
sim.step(3, 600, 5);          % swings down and stops at -0.4 rad
delete(sim);
