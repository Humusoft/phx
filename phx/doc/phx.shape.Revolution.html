phx.shape.Revolution

Profile revolved about an axis

Class  phx.shape.Revolution  |  Superclass: phx.base.Shape

Description

phx.shape.Revolution revolves a user-defined 2-D Profile about the modeling axis to form a solid of revolution. The collision shape is selected by Envelope: the convex hull of the revolved mesh, the exact concave triangle mesh, a bounding cylinder about the revolution axis, or the profile revolved exactly as a stack of truncated cones. The cylinder and the cones are round about the axis, so a rolling body stays smooth where a faceted hull or mesh would not; the cones also follow the profile into grooves and waists. The mass properties are always computed from the actual triangular mesh.

The body is solid when the profile ends on the axis (radius 0). A profile that returns to its first point is a closed loop: it encloses the wall, so the body is hollow where the loop leaves the axis, like a pipe, a cup or a vase; give the wall its thickness by running the loop up the outside and back down the inside, and use Envelope "concave", the only envelope that keeps the cavity open. A profile with an end off the axis that does not return is drawn open, as a surface without thickness, but it weighs as the solid closed at that end by a disc square to the axis: the solid that the "convex", "cones" and "cylinder" envelopes collide with. A hollow part therefore needs the loop, not an open profile.

Creation

Syntax

shape = phx.shape.Revolution shape = phx.shape.Revolution(Name,Value)

Description

shape = phx.shape.Revolution(Name,Value) creates a solid of revolution from the given Profile.

Properties

Geometry

PropertyType / DefaultDescription
ProfileM×2 doubleProfile revolved about the modeling axis; each row is a 2-D point (axial, radial). The generatrix is reversed automatically when it runs the way that would turn the solid inside out, so its direction is not yours to get right. A generatrix reaching the axis closes the body by revolving; one whose last point repeats the first is a loop and makes a hollow body; an end left off the axis is closed square to the axis for the mass (see the description).
Axis"z"Modeling axis: "x", "y" or "z".
Segments45Number of segments around the revolution.
Envelope"convex"Collision envelope: "convex" hull, "concave" triangle mesh, bounding "cylinder" about the revolution axis, or "cones". The cylinder takes its radius from the largest radius in the profile and its half height from the profile's axial reach, centred on the shape origin. The cones revolve the profile exactly, one truncated cone per segment: round about the axis, as polygonal along it as the profile. They need one radius per height, so the axial coordinates of the profile must not turn back (no bore, cup or overhang; points running along the axis at its ends are fine), otherwise an error phx:Revolution:profileNotMonotonic is raised. Tens of segments are cheap; hundreds cost about as much as the concave mesh.
Density1000Volumetric density, kg/m³.

Appearance properties are inherited from phx.base.Shape.

Meshes for flexible and soft bodies

A solid of revolution cannot yet generate meshes for a phx.FlexibleBody or a phx.SoftBody: generateVolumetricMesh and generateSurfaceMesh raise an error until a future release adds them. Until then, give the body a mesh of its own, for example one that PDE Toolbox generates. See Meshes from shapes.

Examples

Revolve a profile into a hollow vase

The loop starts on the axis, runs up the outside, back down the inside 3 cm in, across the bottom and along the axis to its first point.

phx.extra.Viewer("clear", "DefaultCameraPosition", [10 10 10]);

t = linspace(0, 1, 20)';
r = 0.3 + 0.2*sin(t*pi);
profile = [0 0; t r; flipud([t(2:end) r(2:end) - 0.03]); t(2) 0; 0 0];   % [axial, radial]

b = phx.Body("Shape", phx.shape.Revolution("Profile", profile, "Envelope", "concave"));

sim = phx.Simulation;
sim.step(2, 200, 1);

Roll a bottle on its side

phx.extra.Viewer("clear", "DefaultCameraPosition", [2 2 1]);
phx.Body("Type", "static", "Position", [0 0 -0.05], "Shape", {"Box", "Size", [4 2 0.1]});

bottle = [0 0; 0 0.04; 0.15 0.04; 0.2 0.015; 0.25 0.015; 0.25 0];   % [axial, radial]
b = phx.Body("Position", [-1 0 0.04], "Shape", phx.shape.Revolution("Profile", bottle, "Axis", "y", "Envelope", "cones"));
b.LinearVelocity = [1 0 0];
b.AngularVelocity = [0 1/0.04 0];      % rolling without slip

sim = phx.Simulation;
sim.step(2, 400, 1);
