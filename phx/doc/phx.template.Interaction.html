phx.template.Interaction

Template for a custom interaction between two bodies

Class  phx.template.Interaction  |  Superclass: phx.base.Object

Description

phx.template.Interaction is a starting point for writing your own simulable object: a class that takes part in the simulation pipeline like the built-in springs and force elements. Write one when phx.Function is no longer enough — when the element needs its own properties and graphics, or when many instances should be computed together in one call.

The template works as it is: it pulls two bodies towards each other by a constant force and draws a line between them. Every part of the class carries a comment explaining its role.

Creation

Syntax

obj = phx.template.Interaction(bodyA,bodyB) obj = phx.template.Interaction(___,Name,Value,...)

Description

obj = phx.template.Interaction(bodyA,bodyB) creates the interaction between the two phx.Body objects and draws it into the axes of bodyA.

obj = phx.template.Interaction(___,Name,Value,...) sets the properties given as name-value pairs.

Properties

PropertyDefaultDescription
Force10 Magnitude of the force pulling the bodies together, N. A negative value pushes them apart.

Writing Your Own Class

Copy the file into a folder of your own, rename the class and replace the two remaining references to phx.template.Interaction inside it (the Options argument of the constructor and the initial call of updateView). Then adapt the parts below.

PartRole
Constructor Sets SimulationOrder and RedrawOrder, binds the object to its parents with addChild and processes the name-value arguments. Both are wrapped in try/catch with abandon, so that a failed construction leaves nothing behind in the parents. The graphics objects are created here once.
checkObject Reports whether the object has what it needs, usually two valid parents. When a parent is deleted, an object that no longer passes the check is deleted too. Keep it free of side effects.
initObject Prepares the object whenever the simulation rebuilds its pipelines, for example creates an engine counterpart. Returns false to leave the object out.
destroyObject Releases what initObject created. Called from delete.
resolveState Static. The computation of each (sub)step, here the force applied to both bodies.
updateView Static. The drawing of each redraw, here the line between the bodies.
Performance. resolveState and updateView receive all objects of the class in the scene in one cell array. Loop over them inside the method, and route all engine access through phx.engine.io or the methods of phx.Body.

Examples

Two bodies pulled together in zero gravity

clf; view(3); axis equal; grid on;

A = phx.Body("Position", [-2 0 0]);
B = phx.Body("Position", [2 0 0]);
phx.template.Interaction(A, B, "Force", 2000);

sim = phx.Simulation(gca, "Gravity", [0 0 0]);
sim.step(3, 300, 3);
