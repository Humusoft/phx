phx.shape.Mesh

Triangular mesh shape (imported from a file or built from data)

Class  phx.shape.Mesh  |  Superclasses: phx.base.Shape, phx.base.ShapeMesh

Description

phx.shape.Mesh is a general triangular-mesh shape. Its geometry is either loaded from a file through the Source property (STL, Wavefront OBJ and Stanford PLY are supported) or supplied directly as data through Vertices, Normals, Faces and UV. An OBJ file is loaded as a single body with all of its objects and materials merged; its diffuse colors and textures are taken automatically from the referenced .mtl materials. To turn a multi-object OBJ into separate bodies, use phx.assembly.import instead. A PLY file loads as a single mesh; its per-vertex color is averaged into one diffuse color (per-vertex color is not rendered).

The collision shape is selected by Envelope. A bounding "box", "cylinder" or "sphere" fits a smooth primitive to the mesh (cylinder and sphere keep rolling bodies from juddering), while "convex" uses the convex hull (dynamic, the default) and "concave" uses the exact triangle mesh (best kept static). Mass properties are computed from the mesh volume and Density, falling back to the bounding box for non-solid meshes.

Creation

Syntax

shape = phx.shape.Mesh shape = phx.shape.Mesh(Name,Value)

Description

shape = phx.shape.Mesh(Name,Value) creates a mesh shape. Give a Source file, or supply Vertices and Faces directly (with optional Normals and UV).

As a shorthand a body can build the shape inline from a file name: phx.Body("Shape", {"file.stl", "Envelope", "cylinder"}), which is equivalent to passing phx.shape.Mesh("Source", "file.stl", "Envelope", "cylinder").

Appearance properties are inherited from phx.base.ShapeMesh and skeletal properties from phx.base.Shape. A manually set Texture fills in materials that carry no texture of their own.

Examples

Import an STL as a rolling wheel

shape = phx.shape.Mesh("Source", "wheel.stl", "Scale", 0.01, "Envelope", "cylinder");
b = phx.Body("Shape", shape);

Import a textured OBJ

% Colours and textures come from the OBJ's .mtl materials
b = phx.Body("Shape", {"cottage.obj", "Envelope", "convex", "Scale", 2});

A body from a custom triangulation

phx.extra.Viewer("clear", "DefaultCameraPosition", [10 10 10]);

[X, Y, Z] = sphere(16);
fv = surf2patch(X, Y, Z, "triangles");

b = phx.Body("Shape", phx.shape.Mesh("Vertices", fv.vertices, "Faces", fv.faces));

sim = phx.Simulation;
sim.step(2, 200, 1);
