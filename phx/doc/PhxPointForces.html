PhxPointForces

PHX Point Forces block: total force and moment of forces acting at given points

Simulink block  |  Library: PhxLibrary.slx

Description

The PHX Point Forces block sums forces that act at fixed points into one force and one moment about a reference point. With N force inputs F1…FN, each acting at the corresponding row Pk of Points, the outputs are

F = F1 + F2 + ... + FN
M = (P1 - Origin) x F1 + ... + (PN - Origin) x FN  (+ T)

where T is the optional pure torque input. The forces, the points and the results are all expressed in one frame; the block does no rotation.

Its use with PHX is to drive a body by several forces at once, such as the rotors of a drone or the legs of a walking robot. A phx.Body takes a force at its centre of mass and a torque, both in its own frame, through the properties AppliedForce and AppliedTorque. Express the forces and points in the body frame, set Origin to the centre of mass, and connect F and M to the input ports Name.AppliedForce and Name.AppliedTorque of a PhxModel block. The forces then turn with the body, as forces fixed to it should.

The block is a masked subsystem of plain Simulink blocks (a Mux and two matrix Gains), so it also works in models without PHX. Its mask initialization, phx.simulink.pointForces, computes the gain matrices from the parameters and sets up the input ports.

Parameters

ParameterType / DefaultDescription
Points[0 0 0] Points where the forces act, an N-by-3 matrix with one row [x y z] per force. The number of rows sets the number of force inputs.
Origin[0 0 0] Reference point of the moment M, a 1-by-3 vector.
TorqueInputoff Adds the input T, a pure torque that is added to the moment.

Ports

Inputs 1…N, labelled F1…FN, are the forces, one 3-element vector each. With TorqueInput on, input N+1, labelled T, is a 3-element torque. Output 1, F, is the total force and output 2, M, the moment about Origin, both 3-element vectors. The block is a direct feedthrough.

When you change the number of points, the input ports that remain keep their connections.

Examples

Four rotors of a quadcopter

Build the scene with a body named Drone whose motor mounts sit in its own frame at [±0.3 ±0.3 0]. Give the block these mounts as Points and [0 0 0], the centre of mass of a box body, as Origin. Each rotor input is its thrust along the body Z axis, [0 0 fk]; the reaction torques of the propellers enter through T as [0 0 kQ*(f1 - f2 + f3 - f4)].

% PHX Point Forces parameters
Points      = [0.3 0.3 0; -0.3 0.3 0; -0.3 -0.3 0; 0.3 -0.3 0]
Origin      = [0 0 0]
TorqueInput = on

% PHX Model input ports, connected to the outputs F and M
Drone.AppliedForce
Drone.AppliedTorque
Centre of mass. For points given relative to the body origin, Origin is the CenterOfMass of the body. It is [0 0 0] for a box, sphere, cylinder, capsule or straight tube; a cone, a mesh or any body given a centre of its own has it elsewhere.
