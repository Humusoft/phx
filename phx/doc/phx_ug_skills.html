AI Agent Skills

Teaching an AI coding assistant to write PHX code that works

What they are

PHX ships with a set of skills — short instruction documents that teach an AI coding assistant how this toolbox is actually used: which class to reach for, what the properties mean, and which pitfalls to avoid. They are ordinary Markdown files, so any assistant that can read a file can use them; assistants with built-in skill support (such as Claude Code) pick the right one on their own, based on what you are asking for.

The point is accuracy. Without them an assistant will guess an API that looks plausible and produce code that does not run. With them it writes scenes against the real PHX API of the version you have installed.

SkillWhat it covers
phx-scene-basicsThe starting point: bodies, shapes, imported geometry, prefab assemblies, the viewer, stepping a simulation, running headless.
phx-constraints-forcesJoints, springs and ropes, thrusters, buoyancy, fields, applied forces and torques, scripted and closed-loop control.
phx-logging-viewLogging signals, motion traces, measurements, detection zones, camera and the interactive viewer.
phx-engine-gotchasThe engine gateway, error identifiers and the behavior worth knowing when something does not simulate as expected.
phx-simulinkDriving a PHX scene from Simulink through the PHX block.

Where they are

The skills are installed with the toolbox, in the skills folder next to the PHX code. Ask MATLAB for the folder and open it:

skills = fullfile(fileparts(which("phxdoc")), "skills")
winopen(skills)     % Windows; use "open" on macOS, "xdg-open" on Linux

Each skill is one folder with a single SKILL.md file inside, for example skills/phx-scene-basics/SKILL.md.

How to use them

Assistants with skill support

Copy the skill folders where your assistant looks for them and it will load the right one by itself. For Claude Code that is a .claude/skills folder, either inside the project you are working in, or in your home folder to make them available everywhere:

skills = fullfile(fileparts(which("phxdoc")), "skills");
target = fullfile(pwd, ".claude", "skills");   % this project only
% target = fullfile(userpath, "..", ".claude", "skills");  % all projects

mkdir(target);
copyfile(fullfile(skills, "*"), target);

After that just describe what you want in plain language — "build a PHX scene with a crate sliding down a ramp and log its velocity" — and the assistant consults the matching skill on its own. You do not name the skills yourself.

Any other assistant

The files are plain Markdown. Attach or paste the relevant one into the conversation as context before asking for code. Start with phx-scene-basics; add phx-constraints-forces when the scene needs joints, springs or actuators, and the others as the task calls for them.

Note. The skills describe the API of the PHX version they were installed with. After upgrading the toolbox, copy them again so your assistant does not work from an outdated description. They are instructions for writing code, not a replacement for this User Guide — what an assistant produces is still worth reading before you run it.
