phx.TorsionSpring

Torsion spring-damper between two bodies

Class  phx.TorsionSpring  |  Superclass: phx.base.Object

Description

phx.TorsionSpring is a combined element consisting of an ideal torsion spring, an ideal rotary damper and, with a nonzero Inertance, an ideal rotary inerter in parallel. It acts about the z axis of TransformA with the torque M = Stiffness·(Angle - RestAngle) + Damping·rate + Inertance·acceleration, where rate and acceleration are those of the angle. It only turns the bodies about the axis: put it on a hinge (phx.RevoluteJoint) with the same frames to spring the hinge.

The angle is that of the joints: of the x axis of frame B about the z axis of frame A. While the simulation runs it is followed continuously, so the spring winds over any number of turns, like a clock spring. The physics engine solves the spring together with the joints and contacts, by a step that keeps its energy and stays stable at any stiffness, damping and inertance. The frames are read when the simulation starts.

Creation

Syntax

spring = phx.TorsionSpring(bodyA,bodyB) spring = phx.TorsionSpring(___,Name,Value)

Description

spring = phx.TorsionSpring(bodyA,bodyB) creates a torsion spring between two bodies about the z axis of their frames of origin. Set other frames with TransformA and TransformB, as for the joints.

Input Arguments

ArgumentTypeDescription
bodyA, bodyBphx.Body (scalar)The two bodies the spring connects.

Properties

PropertyType / DefaultDescription
TransformAeye(4)Frame of the spring in the local space of body A; the spring acts about its z axis.
TransformBeye(4)Frame of the spring in the local space of body B.
RestAngle0Angle at which the spring is relaxed, rad.
Stiffness1Torsional stiffness, N·m/rad.
Damping0Rotary damping coefficient, N·m·s/rad.
Inertance0Rotary inertance of an inerter in parallel, kg·m²: a torque proportional to the relative angular acceleration about the axis.
Radius0.1Radius of the drawn symbol, m.
OverlayfalseDraw the spring as an overlay (always on top).
Torque1×3 double (read-only)Torque acting on the first body, N·m; the second body gets the opposite torque.
Angledouble (read-only)Angle of frame B about the axis, rad: within [−π, π] before the simulation starts, then continuous over the turns.
Energydouble (read-only)Elastic energy stored in the spring, J (dependent).

Examples

A sprung door

clf; view(3); axis equal; grid on; camlight headlight;

frame = phx.Body("Type", "static", "Shape", {"Box", "Size", [0.1 0.1 2]});
door  = phx.Body("Position", [0.5 0 0], "Shape", {"Box", "Size", [0.9 0.05 2]});

T = [eye(3) [-0.5 0 0]'; 0 0 0 1];           % hinge axis at the door edge
phx.RevoluteJoint(frame, door, "TransformB", T);
phx.TorsionSpring(frame, door, "TransformB", T, ...
    "Stiffness", 50, "Damping", 10, "RestAngle", 0);

door.AngularVelocity = [0 0 3];                % push it open
sim = phx.Simulation("Gravity", [0 0 0]);
sim.step(5, 1000, 10);
